OUTCOME DEFINITIONS

How the replay uses each status

  • Approved: score below the approval threshold.
  • Challenged 3DS: score between the approval and block thresholds.
  • Blocked: score at or above the block threshold.
  • In Review: a separate manual investigation status; it can coexist with a simulated decision.
Rules are stored in the project's SQLite database and apply only to this demonstration app.
